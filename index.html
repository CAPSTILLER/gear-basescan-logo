GEAR BaseScan logos

Public logo files for the GEAR token on Base (0x5880cD05605A549f1DAb01a53ca61Ee559244bD1). Use the tight-crop SVG for BaseScan and the PNGs for CoinGecko and the Base app.

Primary: tight crop GEAR

Cap's own pixel art, cropped tight, nearest-neighbor only. The 32x32 SVG has a one-tile black border on every side. The 512 and 256 PNGs fill the whole square. Files are named gear-logo-tight-*.
