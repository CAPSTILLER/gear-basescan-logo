# gear-basescan-logo

Static GEAR token logo files for Capstiller. Served at https://svg.gearup.wtf (GitHub Pages).

## Files
- `gear-logo-32x32.svg` / `gear-logo-64x64.png` - older small files (64x64 is the page favicon)
- `gear-logo-cutout.png` - footer link used across the Gear apps

The `public/` folder mirrors the root so either can be served.

## Token logo sets
Built only from Cap's own pixel art (64x16 art pixels, nearest-neighbor scaling, no smoothing).
- `gear-logo-tight-32x32.svg`, `gear-logo-tight-512x512.png`, `-256x256.png` - tight crop (32px SVG has a one-tile black border)
- `gear-logo-grid-*` - same art as a 2x2 grid (32px SVG has a one-tile black border)
- `gear-logo-cutout.png` - footer logo, 512x128, black cropped out
